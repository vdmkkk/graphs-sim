## Сбор данных (только на постоянно включённой машине)

```
pip install -r requirements.txt
python -m collector.service        # MQTT непрерывно + кэш ONEmesh раз в 2 ч + полный снимок раз в сутки
```

Постоянный запуск: systemd (см. `docs/данные.md`), `run_service.sh` или `run_service.bat`.
Данные — в `data/raw/` (в git не попадают), состояние — `data/raw/status.json`.
