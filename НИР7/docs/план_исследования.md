# НИР7 — план исследования

**Тема:** «Экспериментальное исследование физического уровня LoRa mesh-сетей и обоснование
аппаратной конфигурации узлов для оффлайн-коммуникаций». Научрук (Курочкин И. И.) дал зелёный
свет 16.10.2026. Срок сдачи — **середина ноября 2026**.

## 1. Логика

Аппаратная конфигурация узла → характеристики радиоканала → вероятность успешной передачи по
отдельному каналу → надёжность, задержка, покрытие и нагрузка всей mesh-сети.

Порядок работы (по файлу «Ограничения модели НИР7.docx»):
1. по открытым данным живой московской сети Meshtastic выявляются статистические закономерности;
2. формулируется физическое объяснение и прогноз; моделирование только подкрепляет гипотезы;
3. собственный узел известной конфигурации включается в ту же сеть и проверяет прогноз.
   Протокол фиксирован (Meshtastic), чтобы выделить эффект железа.

## 2. Данные и расчёты по времени

- **Первичный расчёт — сразу**, на уже имеющейся неделе 08.10–16.10.2026 (снимок истории карты

- **Повторение того же конвейера** по мере сбора (примерно раз в неделю) — оценки уточняются,

## 3. Гипотезы

**Уровень «железо → канал»**

**Г1. Высота установки влияет сильнее модели устройства.**
- Данные: SNR/RSSI прямых линий (пакеты с `hop_start − hop_limit = 0`, шлюз ↔ отправитель
  с известными координатами), высота узла − высота рельефа (DEM), класс железа.
- Метод: регрессия SNR ~ log10(d) + высота над землёй + класс железа (+ случайные эффекты узлов);
  сравнение величины эффектов.
- Натурно: один узел в одной точке на разной высоте (окно / этаж / крыша).

**Г2. Асимметрия линии выдаёт мощность передатчика.**
Потери на трассе в обе стороны одинаковы, усиления антенн входят в оба направления и
сокращаются, поэтому SNR(A→B) − SNR(B→A) ≈ (P_tx,A − P_tx,B) + (N_A − N_B).
- Данные: двусторонние SNR из трассировок (`snr_towards` / `snr_back`) + из NeighborInfo.
- Результат: метод оценки реальной мощности чужих узлов без доступа к ним (закрывает
  ограничение 3.3 «неполнота метаданных»).
- Натурно: меняем мощность своего узла на известную величину → асимметрия должна сдвинуться
  на ту же величину.

**Г3. Карманные устройства систематически проигрывают N дБ.**
T1000-E, Mesh Pocket, T-Echo со встроенными антеннами против плат с внешней антенной
(Heltec V3/V4, T114) при сопоставимых расстояниях.
- Метод: «аппаратная поправка» в дБ как фиксированный эффект класса в модели Г1.
- Натурно: V3 / V4 / MeshPocket в одной точке.
- Мост в НИР8: готовый теоретический порог для носимого узла.

**Г4. Город затухает быстрее, чем модель НИР6.**
Откалиброванная по Москве лог-дистанционная модель покажет показатель n заметно больше 2,08
(Bor et al., использован в НИР6) и бо́льший разброс σ, особенно в плотной застройке; без
калибровки модель НИР6 переоценивает дальность в городе.
- Данные: RSSI прямых линий + мощность передатчика по классу железа (или из Г2).
- Ограничение: координаты огрублены до 180–360 м → оценка надёжна на линиях от ~1 км.

**Г5. В центре дальность ограничивает шум, а не только застройка.**
Уровень шума на приёмнике ≈ RSSI − SNR. В центре и плотной застройке он выше теплового
(−174 + 10·log10(250 кГц) + NF ≈ −120 дБм), и часть потери дальности объясняется этим.
- Данные: RSSI и SNR на шлюзах с координатами; сравнение по классам среды.
- Натурно: замер шумового фона своим узлом (и RTL-SDR) в нескольких районах.

**Уровень «канал → сеть»**

**Г6. Сеть держится на «хребте» из немногих узлов.**
Небольшая доля высоко поставленных и мощных узлов (~10 %) выполняет бо́льшую часть
ретрансляций.
- Данные: `relay_node` в многохоповых пакетах (разрешение 1 байта по соседству и координатам),
  граф соседства (NeighborInfo + трассировки).
- Метод: доля ретрансляций по узлам (кривая Лоренца / Джини); перколяция — удаление
  хребтовых узлов против случайного удаления.

**Г7. Модель НИР6 после калибровки описывает реальную сеть.**
Подставляем в модель протоколов НИР6 измеренные параметры (MEDIUM_FAST, n и σ из Г4, реальную
плотность, hop_limit 7) — она должна воспроизвести наблюдаемые распределения числа хопов и
загрузки канала. Код модели копируется в `НИР7/` отдельными файлами (общих файлов с НИР6 нет).
Попутно закрывает ограничение 2.14 (переход от каналов к сетевым метрикам).

## 4. Дополнения к «Ограничениям модели НИР7»

- Координаты в открытых данных огрублены: `position_precision` 16–17 бит ≈ 360 / 180 м,
  в прошивке 2.8 — не точнее 729 м.
- Видны только пакеты, дошедшие до какого-либо MQTT-шлюза (≈60–80 шлюзов в Москве).
- `relay_node` — 1 байт; без разбора по соседству неоднозначен.
- Высота узла — GPS / ручная (MSL), ошибка десятки метров; встречаются выбросы (999999999).
- Часть узлов в Москве выставляет не регион RU (например, NZ_865) — вероятно, ради большей
  разрешённой мощности; это фактор аппаратной конфигурации, считаем отдельно.
- История карты начинается 08.10.2026; сезонные эффекты не охватываются.

| антенна 868 МГц SMA 3–5 dBi + кабель 3–5 м | 1 | сравнение антенн при одинаковом монтаже, вынос в окно (Г1) |
| RTL-SDR v4 (опционально) | 1 | шумовой фон (Г5), относительная мощность (Г2) |

исходникам прошивки ещё не сверено). Платы не включать без антенны.
